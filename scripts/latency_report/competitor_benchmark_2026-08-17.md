## 2. Prompt 攻擊

- OPENPOINT：罐頭拒答 **~1~1.5s** 出現 → 前面有分類/guard 層擋掉，沒進主 LLM；語氣劫持題能「丟語氣、留問題」，做得好。守 9/9。
- 萬家福：「超出服務範圍」也是秒級罐頭（有分類層），但**兩種洩漏型攻擊穿透** — 分類層只認「越界話題」，認不出「要你描述自己」；洩漏內容顯示其 prompt 結構為「知識庫資料 + 簡短描述 + 列識別碼 + 找不到給客服電話」。守 6/8。
- 我們 POC：**尚未實測**（今天錄的「家樂福」是萬家福官方）。以我們 25 條 regex，案例 1、2 也**不會被規則攔**（無「忽略/指令/prompt」字眼），關 LLM guard 後就看模型 — 建議下一輪就用這兩題打我們自己。

## 3. 給 PM 的三句話
1. 速度：三家都在 5 秒上下打轉，沒有人做到穩定 ≤5s；差異在「等待體感」（OPENPOINT 3 秒狀態訊息）與「答對率」（萬家福 follow-up 全倒）。
2. 我們的差異化：真的會轉真人（Flex 按鈕）、follow-up 改寫、DM 圖卡；補上 3 秒狀態訊息 + 建議問題 quick reply 就能在體感上追平。
3. 安全：官方 LINE 的智慧小幫手 2/8 洩漏 prompt，是可以直接拿出來講的對照案例；我們要先確認自己在同兩題守得住。
