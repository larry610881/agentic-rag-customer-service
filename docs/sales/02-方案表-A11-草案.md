## 二、每欄的業務講稿句

- Free 自助：「不用找我們，五分鐘自己開一個，先用真的文件試試看。」
- Standard：「確定要用了，加上 LINE 與完整監控，兩週內上線。」
- Pro：「多部門、多機器人，一份儀表板看用量與品質，還能用 API 接進你們自己的系統。」

## 三、Enterprise 為什麼不放進表

專案型客戶（例：7-ELEVEN 虛擬門市）的需求是獨立部署、Cloud Run IAM 或私網、資安送檢配合、SLA 與駐點，這些是 Deck B 的服務商品，不是平台方案。A-11 表下方加一行「需要獨立部署與資安配合？請看服務方案」導到 B 版即可。

## 四、Free 自助上線前必須定案的事（不定案不能對外開放）

1. 額度硬上限與全平台月費用熔斷數字。
2. 個資與資料保留條款、行銷信同意（預設不勾、可取消訂閱、寫 audit log）。
3. 防濫用：Email 驗證、每 IP 每日註冊數、拋棄式信箱黑名單、註冊頁驗證碼。
4. 程式前提：租戶 API key 與 JWT 改版（agentic-rag 分支 fix/auth-surface-hardening-p1）已完成，尚缺自助註冊端點、free plan seed、里程碑寄信流程。
