# 給專案負責人的權限申請文案（可直接複製貼上）

專案：`project-pic-ai-innovation-poc`
儲存桶：`gs://poc-rag-documents-project-pic-ai-innovation-poc`

---

你好，POC 環境（project-pic-ai-innovation-poc）的文件儲存桶有兩項設定要麻煩你協助，
我的帳號沒有 `storage.buckets.*` / `storage.buckets.setIamPolicy` 權限，做不了。

**一、給 VM worker 的服務帳號桶內讀寫權**

```bash
gcloud storage buckets add-iam-policy-binding \
  gs://poc-rag-documents-project-pic-ai-innovation-poc \
  --member=serviceAccount:poc-rag-vm-sa@project-pic-ai-innovation-poc.iam.gserviceaccount.com \
  --role=roles/storage.objectAdmin
```

- 用途：背景 worker 要讀使用者上傳的 PDF 做 OCR、寫回切頁後的子檔。
- 現況：worker 取檔時被擋 `403 storage.objects.get`，目前靠資料庫副本暫時繞過，
  但走簽名網址直傳的大檔沒有副本可用，一定會失敗。
- 範圍：只在這一個桶上授權，不是專案層級。

**二、設定這個桶的 CORS，讓後台可以瀏覽器直傳**

把下面存成 `cors.json`：

```json
[
  {
    "origin": ["https://agentic-rag-969010424468.asia-east1.run.app"],
    "method": ["PUT", "GET", "HEAD"],
    "responseHeader": ["Content-Type", "x-goog-resumable"],
    "maxAgeSeconds": 3600
  }
]
```

再執行：

```bash
gcloud storage buckets update \
  gs://poc-rag-documents-project-pic-ai-innovation-poc \
  --cors-file=cors.json
```

- 用途：後台上傳文件是前端拿簽名網址後直接 PUT 到 GCS，桶沒有 CORS 設定時
  瀏覽器預檢會被擋，畫面顯示「GCS upload network error」。
- 只允許上面那一個來源網域與 PUT/GET/HEAD，不開放公開讀取。

兩項都設定完成後再麻煩告知，我這邊會把暫時的資料庫副本繞道關掉，改回走 GCS。
